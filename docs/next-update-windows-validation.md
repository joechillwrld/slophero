# Next-update Windows validation (private development run)

Install the 0.4.149 private test ZIP from `slophero-v1.1-alpha`. Keep 0.4.148 as a rollback. The new log must contain `SlopHero 0.4.149 private test build`. Use the matching Clone Hero v1.1.0.6142 build and the same chart, note skin, resolution, render interval, and mod settings for each comparison. Save the new `Latest.log` and raw PresentMon per-frame CSVs; summary-only CSV rows cannot establish the active frames.

1. Enable **Compact score + combo HUD** in offline solo Quickplay. Verify the native score/combo digits and star/song-progress artwork stay hidden throughout play and the replacement numbers match. Toggle Score, Combo, Song time, and Stars separately; check `m:ss/m:ss` time and native-equivalent stars. Set **Compact score color**, then drag the **Move compact score** preview. Pause, open settings, and exit: all native sprites must return. Look for `Compact score HUD hid 35` in `Latest.log`.
2. On the reported full song whose chart ends well before 36 seconds, enable manual outro mode and let the last note pass. The prompt should appear in the blank silence; hold End and verify the normal results screen. Repeat with automatic mode. If it remains closed, retain the `Outro gate` lines with `lastHead`, `blockingIndex`, and `tail`. Also test a chart with a hit final sustain: neither mode should cut off its tail or a future note. Check scores, streak, and saved attempts after the transition.
3. Enable the ghost sound filter. Break a combo with a ghost input, then miss a chart note. Only the ghost break should be silent. The log gives a per-song suppressed/eligible sound-call count when the hook is removed.
4. Pause and resume a song, restart shortly after starting, and loop a practice section. In the section, Misses must start at zero or above, increase only for judged misses, and remain correct after a late accepted hit. Pause/resume must not increment attempts; a restart or practice rewind must increment once. Check the shorter HUD labels. Try per-song save only, global save only, and both, then relaunch to confirm totals persist. `Latest.log` prints each counted attempt.
5. Cycle **Next game font** on the Counter HUD page and check the live sample at the counter position before restarting. First confirm scrolling notes remain visible and rainbow colors stay stable with the experimental native rainbow switch off. `Latest.log` should report `Rainbow notes resolved lane colors from ClonZones head sprites`. Then enable the native bridge and compare new and recycled notes while scrolling; `Latest.log` should report `Experimental rainbow bridge recolored an exact-game note setter call`. Turn it off if notes disappear or performance drops. Then test FPS color, star-progress fill with an untinted empty track, random palette limits, and outro skipping. Capture a highway thumbnail while notes are on screen and verify the PNG has transparent pixels outside the highway in `UserData/SlopHero/Thumbnails`.
6. For performance work, start with the supplied 0.4.141 settings as a baseline. Repeat same-chart A/B pairs for the confirmed compact HUD, then for one optional native sustain or camera setting at a time. Record the log activation line, average presents/s, P99 frame interval, CPU busy, GPU busy, and any visual or input regression. Do not combine unverified switches into a claimed gain.

No new release package should be made until the gameplay checks pass and performance conclusions are tied to confirmed activation and matched captures. Replay/demo and chart-preview rendering, plus bundled fonts, are deferred to a later build by the user.
