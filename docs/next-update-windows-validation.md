# Next-update Windows validation (private development run)

Install the 0.4.145 private test ZIP from `slophero-v1.1-alpha`. Keep 0.4.144 as a rollback. The new log must contain `SlopHero 0.4.145 private test build`. Use the matching Clone Hero v1.1.0.6142 build and the same chart, note skin, resolution, render interval, and mod settings for each comparison. Save the new `Latest.log` and raw PresentMon per-frame CSVs; summary-only CSV rows cannot establish the active frames.

1. Enable **Compact score + combo HUD** in offline solo Quickplay. Verify the native score/combo digits and star/song-progress artwork stay hidden throughout play and the replacement numbers match. Set **Compact score color**, then drag the **Move compact score** preview. Pause, open settings, and exit: all native sprites must return. Look for `Compact score HUD hid 35` in `Latest.log`.
2. Test the blank-outro selector on a song with a long sustained final chord. Manual mode must show `Notes are done` only after the last child tail ends, and holding End must reach the normal results screen. If no prompt appears, retain the new `Outro gate` diagnostic lines in `Latest.log`. Automatic mode must wait for the same point. Try a chart with notes near the audio end: neither mode should cut off a playable note. Check scores, streak, and saved attempts after the transition.
3. Enable the ghost sound filter. Break a combo with a ghost input, then miss a chart note. Only the ghost break should be silent. The log gives a per-song suppressed/eligible sound-call count when the hook is removed.
4. Pause and resume a song, restart shortly after starting, and loop a practice section. In the section, Misses must start at zero or above, increase only for judged misses, and remain correct after a late accepted hit. Pause/resume must not increment attempts; a restart or practice rewind must increment once. Check the shorter HUD labels. Try per-song save only, global save only, and both, then relaunch to confirm totals persist. `Latest.log` prints each counted attempt.
5. Cycle **Next game font** on the Counter HUD page and check the live sample at the counter position before restarting. Test rainbow notes while scrolling, including new and recycled notes; `Latest.log` should report that the player camera pre-render callback was reached. Then test FPS color, star-progress fill with an untinted empty track, random palette limits, and outro skipping. Capture a highway thumbnail while notes are on screen and inspect the PNG in `UserData/SlopHero/Thumbnails`.
6. For performance work, start with the supplied 0.4.141 settings as a baseline. Repeat same-chart A/B pairs for the confirmed compact HUD, then for one optional native sustain or camera setting at a time. Record the log activation line, average presents/s, P99 frame interval, CPU busy, GPU busy, and any visual or input regression. Do not combine unverified switches into a claimed gain.

No new release package should be made until the gameplay checks pass and performance conclusions are tied to confirmed activation and matched captures. Replay/demo and chart-preview rendering, plus bundled fonts, are deferred to a later build by the user.
