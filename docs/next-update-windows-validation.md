# Next-update Windows validation (private development run)

Do this only after installing the 0.4.142 private test ZIP from the private `slophero-v1.1-alpha` branch. Keep the existing 0.4.141 package as a rollback. The new log must contain `SlopHero 0.4.142 private test build` to identify the DLL. Use the matching Clone Hero v1.1.0.6142 build and the same chart, note skin, resolution, render interval, and mod settings for each comparison. Save the new `Latest.log` and raw PresentMon per-frame CSVs; summary-only CSV rows cannot establish the active frames.

1. Enable **Compact score + combo HUD** in offline solo Quickplay. Verify the native score and combo sprites disappear, the two numbers match the game's scoring, and the miss/ghost counters remain a separate movable HUD. Pause, open settings, and exit: the native sprites must return. Look for `Compact score HUD replaced 23` in `Latest.log`; a one-time warning now explains when the replacement could not activate. Capture a same-chart compact-off/on PresentMon pair only after activation is confirmed.
2. Test the blank-outro selector on a song with a long sustained final chord. Manual mode must show `Notes are done` only after the last child tail ends, and holding End must reach the normal results screen. Automatic mode must wait for the same point. Try a chart with notes near the audio end: neither mode should cut off a playable note. Check scores, streak, and saved attempts after the transition.
3. Enable the ghost sound filter. Break a combo with a ghost input, then miss a chart note. Only the ghost break should be silent. The log gives a per-song suppressed/eligible sound-call count when the hook is removed.
4. Pause and resume a song, restart it, and loop a practice section. Pause/resume must not increment attempts; a restart or practice rewind must increment the relevant counter once. Try per-song save only, global save only, and both, then relaunch to confirm totals persist.
5. Change the counter font to an installed family; check both the ordinary and compact Canvas counter text. Test FPS color, star-progress fill with an untinted empty track, rainbow notes while scrolling, and random palette limits over several attempts. Capture a highway thumbnail while notes are on screen and inspect the PNG in `UserData/SlopHero/Thumbnails`.
6. For performance work, start with the supplied 0.4.141 settings as a baseline. Repeat same-chart A/B pairs for the confirmed compact HUD, then for one optional native sustain or camera setting at a time. Record the log activation line, average presents/s, P99 frame interval, CPU busy, GPU busy, and any visual or input regression. Do not combine unverified switches into a claimed gain.

No new release package should be made until the gameplay checks pass and performance conclusions are tied to confirmed activation and matched captures. Replay/demo and chart-preview rendering, plus bundled fonts, are deferred to a later build by the user.
